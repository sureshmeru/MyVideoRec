# Feature support matrix

Status definitions:

- **Implemented**: application code exists.
- **Automated-tested**: covered by a local automated test.
- **Device-dependent / unverified**: requires physical-device or platform testing not completed in
  this environment.
- **Not implemented**: deliberately not represented as working in the UI.

| Capability                                              | Status                                                            | Notes                                                                                                                                                                                                                                                                                                                                                                                                                  |
| ------------------------------------------------------- | ----------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Android / iOS React Native shell                        | Implemented; Android debug build verified                         | Bare React Native 0.75.5; Android `assembleDebug` succeeded on Windows. iOS build has not been run from this environment.                                                                                                                                                                                                                                                                                              |
| Dark automotive UI, five primary tabs, and vector icons | Implemented                                                       | Home, Record, Videos, Trips, Settings; Lucide icons use active/inactive theme colors.                                                                                                                                                                                                                                                                                                                                  |
| Rear/front camera discovery and runtime permission      | Implemented; device-dependent / unverified                        | VisionCamera device selection and permission hooks. Single-camera fallback is always available.                                                                                                                                                                                                                                                                                                                        |
| Supported format selection                              | Implemented; automated-tested                                     | Chooses from the actual device-reported format list and prefers a 30 fps format near 1080p. It does not claim a format is available before discovery.                                                                                                                                                                                                                                                                  |
| Segmented single-camera recording                       | Implemented; device-dependent / unverified                        | Segments are finalized and moved into app-private storage before SQLite indexing. Segment length is configurable.                                                                                                                                                                                                                                                                                                      |
| Microphone capture                                      | Implemented; device-dependent / unverified                        | Disabled by default; permission is requested when enabled and recording starts.                                                                                                                                                                                                                                                                                                                                        |
| SQLite recording metadata                               | Implemented                                                       | Versioned schema includes recordings, upload jobs, trips, trip points, safe-delete reservation, and user clip names; interrupted open trips are finalized on app initialization.                                                                                                                                                                                                                                       |
| Local clip library, playback, rename, and share         | Implemented; device-dependent / unverified                        | Inline player has in-video controls, seeking, time display, frame stepping, track selection, speed control, fullscreen, playlist navigation, loop/shuffle, A-B repeat, bookmarks, timestamp jumps, and resume position. Native player handles playback; share destinations depend on installed apps. Direct Android SAF export is not implemented.                                                                     |
| Advanced audio/video processing                         | Not implemented                                                   | No equalizer, audio boost/balance/delay, still-frame capture, seek thumbnails, or pitch-preserving speed control is exposed by the installed `react-native-video` integration.                                                                                                                                                                                                                                         |
| Protect / manually delete local clips                   | Implemented                                                       | Protected clips cannot be deleted through the storage screen.                                                                                                                                                                                                                                                                                                                                                          |
| Free-space display and recording stop threshold         | Implemented                                                       | Stops before a new segment when under 512 MB.                                                                                                                                                                                                                                                                                                                                                                          |
| Loop recording cleanup / in-transfer protection         | Implemented; automated-tested                                     | Off by default. When enabled, deletes oldest unprotected clips; clips marked queued or uploading are excluded. There is no upload worker yet.                                                                                                                                                                                                                                                                          |
| Foreground GPS trip history and recording location      | Implemented; device-dependent / unverified                        | User starts tracking explicitly; foreground-only permissions; coordinates and accuracy-filtered distance/speed estimates are stored locally.                                                                                                                                                                                                                                                                           |
| Background GPS, route visualization, trip export        | Not implemented                                                   | Tracking stops when app backgrounds; no background location permission is requested.                                                                                                                                                                                                                                                                                                                                   |
| Google Drive, OneDrive, Dropbox OAuth/upload            | Not implemented                                                   | No provider tokens or transfers exist in this build.                                                                                                                                                                                                                                                                                                                                                                   |
| Direct Android SAF / iOS Files document-provider export | Not implemented                                                   | System share sheet is available; direct destination-provider writing remains outstanding.                                                                                                                                                                                                                                                                                                                              |
| Android camera foreground service                       | Implemented; device-dependent / unverified                        | Starts a camera foreground service with an ongoing notification while recording; includes camera and optional microphone service types and their required permissions. The active VisionCamera session is kept active across app-state and tab-focus changes. Android OEM, system privacy, thermal, and process policies can still interrupt capture.                                                                  |
| iOS background or locked-screen recording               | Not supported                                                     | iOS does not allow this camera capture implementation to continue while the app is locked or backgrounded; the app finalizes the clip when it receives the lifecycle transition.                                                                                                                                                                                                                                       |
| Simultaneous front/rear capture                         | Android best-effort implementation; device-dependent / unverified | Android checks Camera2 concurrent camera ID sets and enables two VisionCamera streams only when the OS reports both selected cameras can run concurrently. Saves synchronized front/rear segments as separate clips; audio is captured only on the selected primary camera. iOS dual capture is not implemented because this capture path does not use `AVCaptureMultiCamSession`. Real-device validation is required. |
| 4K, HDR, thermal, interruption guarantees               | Device-dependent / unverified                                     | The app only chooses a reported format; no device certification has been performed.                                                                                                                                                                                                                                                                                                                                    |
| Backend accounts / synchronization                      | Not implemented                                                   | Local recording and playback require no backend.                                                                                                                                                                                                                                                                                                                                                                       |

## Device test record

The Android debug APK compiles with the configured NDK 27.1.12297006, but no physical Android or
iOS device test has been recorded for this repository. Before a release, record device model, OS
version, camera format selected, audio permission result, segment playback result, background/lock
interruption behavior, low-storage behavior, and thermal behavior.
